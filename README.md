## Installation

> As of 8/10/2025, this will not work as I have yet to finish the install and build scripts.

> This project is for Arch-based Linux systems only and is only, and is only tested on Arch Linux.

### Steps

1. Install git with "`sudo pacman -S git`".
2. Run "`git clone https://github.com/Sammyueru/dotfiles-arch.git ./samm-dotfiles-arch`".
3. Enter the new directory with "`cd samm-dotfiles-arch`".
4. Run "`sudo bash ./install.sh`" in the new directory.
5. Wait and answer any given prompts.
